# Как открыть сайт

1. Скачайте репозиторий через **Code → Download ZIP** и распакуйте его.
2. Откройте `index.html` в браузере. Устанавливать Node.js или собирать проект не нужно.
3. Внизу любой страницы раскройте **Explore design directions**, чтобы переключаться между тремя вариантами дизайна.

## Что внутри
- Главная: `index.html`.
- Услуги: `services.html`.
- MOT: `mot.html`.
- Контакты: `contact.html`.
- Общие стили: `styles.css`.
- Интерактивность: `app.js`.
- Источники, ограничения и подготовка к запуску: `README.md`.
- Выполненные проверки: `QA.md`.

Форма не отправляет заявку автоматически: она готовит письмо для вашей почтовой программы. Для отправки нужно отдельно открыть почтовую программу и отправить письмо. Подтверждения онлайн-бронирования здесь нет.

Это концепт редизайна, не официальный действующий сайт мастерской. Перед публикацией нужно согласие владельца и проверка контактов, цен, услуг и расписания.

Репозиторий: https://github.com/lifeworkimpulse-commits/auto

GitHub Pages автоматически не включён. Для просмотра онлайн потребуется отдельная настройка публикации. Секретные ключи или токены в файлы сайта добавлять нельзя.
